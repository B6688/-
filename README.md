# 问卷星自动填写助手

一个基于 Tampermonkey 的问卷星自动填写脚本，支持使用 Moonshot AI 生成智能回答。

## ✨ 功能特点

- 🤖 支持 Moonshot AI 生成智能答案
- 🎯 自动填写单选题、多选题和填空题
- ⏱️ 智能请求限制和队列管理
- 🎨 随机答案生成备选方案
- 📋 简洁的控制面板
- 🔄 自动/手动填写模式

## 🚀 安装步骤

1. 安装 Tampermonkey 浏览器扩展
2. 点击 Tampermonkey 的"添加新脚本"
3. 将脚本代码复制粘贴进去
4. 保存即可使用

## ⚙️ 配置说明

在脚本开头部分配置你的 Moonshot AI API：
  需要去Moonshot官网申请一下key并替换
  Moonshot官网：https://platform.moonshot.cn/
  由于Moonshot官网对于免费的开发者仅支持3次/min，所以本脚本有做超过3次等待1min
  
## 🎮 使用方法

1. 打开问卷星问卷页面
2. 脚本会自动添加控制面板在页面右上角
3. 可以选择：
   - 等待自动开始填写
   - 点击"手动开始"按钮开始填写
   - 填写完成后点击"提交问卷"按钮提交

## 🛠️ 主要功能

- **智能答案生成**：使用 Moonshot AI 生成符合上下文的答案
- **请求限制**：内置请求限制机制，避免 API 调用过频
- **队列管理**：智能管理并发请求
- **随机延迟**：模拟真实填写行为
- **备选方案**：当 AI 生成失败时使用预设答案

## ⚠️ 注意事项

- 请合理使用，避免滥用
- 需要自行配置有效的 Moonshot AI API 密钥
- 建议适当调整请求限制参数
